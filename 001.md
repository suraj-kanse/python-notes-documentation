# Local Python Setup and Execution

Setting up a local environment lets you practice real debugging, file organization, and terminal workflows early on.

## Installing Python

Download Python from [python.org](https://www.python.org). The website detects your operating system and suggests the installer.

- **Windows**: Check the box that says **Add python.exe to PATH** during installation. Without this, your command prompt cannot find the `python` command.
- **Verification**: Run `python --version` (Windows) or `python3 --version` (macOS/Linux) in your terminal. You should see output like `Python 3.12.1`.

## Local Editors vs Online Compilers

Online compilers (like Replit or Online GDB) work fine for quick tests, but they hide the filesystem, terminal interaction, and error traces. Notebook environments like Jupyter or Google Colab work well for data visualization and exploratory analysis, but general application and backend development happens in standard code editors.

### Using VS Code

1. Install Visual Studio Code.
2. Install the official Python extension from Microsoft for syntax highlighting and autocomplete.
3. Name files using `snake_case` (for example, `hello_world.py`), which follows standard Python convention.

## Running Code

Create a file named `greeter.py`:

```python
def greet(name):
    print("Hello,", name)

greet("World")
```

Run the script from your terminal:

```bash
# Windows
python greeter.py

# macOS / Linux
python3 greeter.py
```

Python blocks are defined by indentation (typically 4 spaces) rather than curly braces.

## Importing Files and `__pycache__`

Create a second file named `main.py` in the same directory:

```python
from greeter import greet

greet("Developer")
```

Run `main.py`:

```bash
python main.py
```

When you import a file, Python creates a `__pycache__` directory containing compiled bytecode files (like `greeter.cpython-312.pyc`). Python uses this cached bytecode on subsequent runs to start up faster if the source file has not changed. Online sandboxes hide this behavior, but local environments expose how Python handles module compilation.
