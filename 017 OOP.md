The Analogy: Think of a Class as the plastic mold for making Gujiya (or a blank form at a bank). It doesn't have the filling yet; it just dictates the shape. An Object (or Instance) is the actual physical Gujiya you made using that mold, filled with your specific choice of dry fruits.

When you fill out the bank form with your specific details (Name, ID, Deposit Amount), that filled-out form becomes an Object (an Instance). You can use that single blank form (Class) to create infinite specific customer forms (Objects).

Creating a Class and an Object
Classes in Python are defined using the ```class``` keyword. By convention, Class names should always be capitalized.
```
class Car:
    # The __init__ method is the "Constructor". 
    # It runs automatically the exact moment an object is created.
    def __init__(self, user_brand, user_model):
        
        # 'self' establishes the internal connection line (context)
        # It means "MY brand is whatever the user passed in"
        self.brand = user_brand
        self.model = user_model

# Creating an Object (Instance) from the Class
my_car = Car("Toyota", "Safari")

# Accessing the Object's attributes (variables)
print(my_car.brand) # Outputs: Toyota
```

The ```self``` Keyword (Crucial Interview Concept):
When writing methods inside a Class, the very first parameter must always be ```self```. ```self``` is the wiring that allows the object to refer to its own specific data. (In languages like JS or Java, ```this``` is known as this).

Adding Methods to a Class:
Attributes are the variables (data). Methods are the functions (actions) the Class can perform.
```
class Car:
    def __init__(self, brand, model):
        self.brand = brand
        self.model = model

    # Adding a method
    def full_name(self):
        return f"{self.brand} {self.model}"

my_new_car = Car("Tata", "Nexon")
print(my_new_car.full_name()) # Outputs: Tata Nexon
```

Inheritance: 
Inheritance allows a new Class to take on all the attributes and methods of an existing Class, while adding its own unique features.
```
# ElectricCar inherits everything from Car
class ElectricCar(Car):
    def __init__(self, brand, model, battery_size):
        # super() calls the parent class (Car) to handle the brand and model setup
        super().__init__(brand, model) 
        
        # Now we just handle the new attribute specific to Electric cars
        self.battery_size = battery_size

my_tesla = ElectricCar("Tesla", "Model S", "85kWh")
print(my_tesla.full_name()) # We can use full_name() because it was inherited from Car!
```

Encapsulation (Private Variables):
Encapsulation is the act of hiding internal data so outside users/code cannot access or alter it directly. In Python, you make an attribute private by adding two underscores ```__``` before the variable name.
```
class Car:
    def __init__(self, brand, model):
        self.__brand = brand # Now completely private!

    # We must provide a "Getter" method so users can read the brand safely
    def get_brand(self):
        return self.__brand + "!"

my_car = Car("Tata", "Safari")
# print(my_car.__brand) This will crash! The variable is hidden.
print(my_car.get_brand()) # Safely outputs: Tata!
```

Polymorphism:
Polymorphism means "many forms." It occurs when two different Classes have a method with the exact same name, but they perform differently depending on which object calls it.
```
# In the Car class:
def fuel_type(self):
    return "Petrol or Diesel"

# In the ElectricCar class:
def fuel_type(self):
    return "Electric Charge"

# Both objects use the exact same method name, but output different results!
```

Class Variables: 
Sometimes you need a variable that belongs to the entire Class itself, not to the individual objects. (e.g., Keeping a total count of how many Cars have ever been manufactured).
```
class Car:
    total_car_count = 0 # Class Variable

    def __init__(self, brand, model):
        self.brand = brand
        self.model = model
        Car.total_car_count += 1 # Increments every time a new object is created

c1 = Car("Tata", "Nexon")
c2 = Car("Toyota", "Corolla")
print(Car.total_car_count) # Outputs: 2
```

Decorators (```@staticmethod``` & ```@property```):
Decorators are "enhancements" you stack on top of a method to drastically change how it behaves.

1. ```@staticmethod```
- A static method belongs only to the Class. Objects cannot use it, and it does not take self as a parameter.
```
class Car:
    @staticmethod
    def general_description():
        return "Cars are a means of transport."

print(Car.general_description()) # Works!
# print(my_car.general_description()) Fails! Objects cannot access static methods.
```

2. ```@property``` (Read-Only)
- If you want users to be able to read an attribute without calling a method, but you want to prevent them from changing it, you use ```@property```.
```
class Car:
    def __init__(self, model):
        self.__model = model

    @property
    def model(self):
        return self.__model

my_car = Car("Safari")
print(my_car.model) # We can read it like a normal variable (no parentheses needed)
# my_car.model = "City" CRASH! @property prevents overwriting. It is Read-Only.
```

Multiple Inheritance & Checking Instances:
Python fully supports Multiple Inheritance (a Class can inherit from multiple parent classes simultaneously).
```
class Battery:
    def battery_info(self): return "This is a battery"

class Engine:
    def engine_info(self): return "This is an engine"

# Inheriting from two classes at once
class HybridCar(Battery, Engine):
    pass

my_hybrid = HybridCar()
print(my_hybrid.battery_info()) # Works!
print(my_hybrid.engine_info())  # Works!
```


Instance Checking:
To check if an object was created by a specific class (or inherited from it), use ```isinstance()```.
- ```isinstance(my_tesla, Car)``` ➔ ```True```
- ```isinstance(my_tesla, ElectricCar)``` ➔ ```True```




Summary & Takeaways
- Classes & Objects: A Class is the blank form. An Object (Instance) is the filled-out form.
- ```self```: Mandatory first parameter in methods; it wires the object to its own internal data.
- ```__init__```: The constructor method that executes immediately upon object creation.
- Inheritance: Use ```super().__init__()``` to grab the setup logic from the parent class.
- Encapsulation: Prefix variables with ```__``` to hide them from the outside world.
- ```@property```: A decorator used to make an internal method act like a read-only variable.
- ```@staticmethod```: A method that belongs to the Class itself, stripping away the ```self``` context so objects cannot use it.
